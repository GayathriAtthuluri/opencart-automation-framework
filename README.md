# OpenCart Automation Framework

Selenium automation framework for testing the OpenCart application using Java, Selenium WebDriver, TestNG, Maven, and Page Object Model.

## Technologies

- Java
- Selenium WebDriver
- TestNG
- Maven
- Apache POI
- Log4j2
- ExtentReports
- Git & GitHub

## Framework Features

- Page Object Model (POM)
- Data-Driven Testing using Excel
- Cross-Browser Testing
- Parallel Execution
- ThreadLocal WebDriver
- Explicit Waits
- Logging
- Extent Reports
- Failure Screenshots
- TestNG Listener
- Configuration Management

## Test Scenarios

- User Registration
- User Login
- Product Search
- Add Product to Cart
- Remove Product from Cart
- User Logout
- End-to-End Testing

## Browsers

- Google Chrome
- Microsoft Edge
